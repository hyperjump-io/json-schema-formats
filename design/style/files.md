# Files

- Each module in `src/` is one specification, named after it, like
  `rfc3339.js` for dates and times or `uts46.js` for internationalized
  hostnames. Each one has its formats' `is` and `assert` functions, their
  error classes, and their diagnosis. `openapi.js` is the OpenAPI Format
  Registry's, for the integer formats that it defines itself.
- `src/index.js` re-exports the API, grouped like the JSON Schema
  validation specification groups the formats. `src/index.d.ts` declares
  all of it.
- `src/patterns.js` is generated by `scripts/generate-patterns.js`, which
  has every format's ABNF. Don't edit it (see
  [Grammars](../components/grammars.md)).
- `src/diagnose.js` is what every format's diagnosis is made of (see
  [Diagnosing](../components/diagnosing.md)).
- `src/date-math.js` is the calendar: days in a month, leap years, and
  leap seconds.
- Tests of whether values are valid are in the JSON Schema Test Suite's
  format, so they can be given to the suite. The ones the suite doesn't
  have are in `test-suite/tests/`, laid out like the suite's
  `validation/tests/`, with a file for each format named like the suite's.
  `src/json-schema-test-suite.test.js` runs the suite's and these.
- Other tests are next to the code they test. `src/assert.test.js` tests
  the `assert` functions against the `is` functions, and their errors,
  which the suite's format can't say. `src/email.test.js` tests that
  `isEmail` throws for an unknown address literal tag.
